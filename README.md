# Distributed_Rental_Platform
一个开源的分布式租房平台，旨在方便出租人提供具体简明的租房信息，匹配对应信息的租赁者。

## 项目起源
各个地方租房鱼龙混杂，信息不透明，导致如果不是社会经验丰富的人士经常找到并不心仪的地方。而本分的出租者又可能由于信息闭塞，或者精力不足很长时间没有匹配到承租者。

具体而言。工作的人员大多挤入各大城市的CBD亦或工业区，那么城镇乡村或者某些非工作聚集区会有较多房间的空闲，经历过十几年的大建设时代也导致很多非工作聚集区也有大量的空房。如今2026年，工作岗位供不应求，同时严格符合劳动法的工作岗位较为稀缺，就有很多灵活工作或者正在摸索的人士需要租房生活，同时对地点并不敏感，这个时候就迫切需要一个公开房屋信息且具体罗列每一项信息的平台。

故这个项目的核心点在于信息透明，公平比较，匹配契合度更高的出租方和承租方，减少无效的互选时间成本。

原则上希望这个平台提供一个出租方**直租**承租方的环境。
